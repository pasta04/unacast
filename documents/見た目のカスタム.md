# 見た目のカスタム

## レスの表示背景色や文字色を変更したい (OBS取り込み)
<img src="help/img/help03.jpg" />
例として背景の透明度を変更したい場合は、OBSのブラウザソース設定画面のカスタムCSSに以下のように追加してください

```
  body {  
    background-color: rgba(0, 0, 0, 0.5); /*0.5の部分が透明度指定、0~1の少数で設定でき、0で透明、1で不透明になる*/  
  }  
```

チャット欄に使用しているCSSは以下となります。上書きしたい要素をコピペして利用してください。
- [style-server.css](../public/css/style-server.css)

## レスの表示背景色や文字色を変更したい (chatウィンドウ))
設定画面の「チャットウィンドウのスタイル」で、CSS を入力して変更できます。
- 「項目を選んで挿入」で対象 (名前・本文・背景など) と項目 (文字サイズ・文字色・背景色など) を選ぶと、CSS に書き込まれます。同じ対象のブロックがあれば、その中の値を置き換えます。
- CSS を直接書いても構いません。編集中の内容は、設定画面内のプレビューにすぐ反映されます。
- 「適用」を押すと保存され、チャットウィンドウに反映されます。配信画面 (OBS) には影響しません。

ファイルで指定することもできます。
`resources`フォルダ直下に、`style-server.css`ファイルを置いて、その中にCSSを記載してください。
両方を使った場合は、設定画面で入力した CSS の方が優先されます。
**unpack版**の場合はOBS側と同じファイル(`style-server.css`)を直接編集してもOKです。

なお、chatウィンドウと翻訳ウィンドウの背景色はOBS向けの半透過色とは別に、既定でダークモード相当の `#1e1e1e` が適用されています ([style-window.css](../public/css/style-window.css))。上記のユーザーカスタムCSSで `body { background-color: ... }` を書けば、この既定色も上書きできます。

## chatウィンドウをゲーム画面などに重ねて表示したい
設定画面の「チャットウィンドウのスタイル」の「ウィンドウの表示」で切り替えます。chatウィンドウの右クリックメニューからも切り替えられます。
- **最前面に表示**: 他のウィンドウより手前に表示します。
- **枠なし・背景透過**: タイトルバーを消し、背景を半透明にします。
  - 移動は、ウィンドウ上端のつまみ (マウスを乗せると表示) をドラッグします。
  - 背景の濃さは、スタイル (CSS) の `body { background-color: rgba(0, 0, 0, 0.3); }` のように変えられます (最後の数字が不透明度)。
  - 切り替えるとchatウィンドウを作り直します (表示中のコメントは引き継ぎます)。
- **クリック透過**: マウス操作が後ろのウィンドウに届くようになります。
  - 有効中はchatウィンドウを操作できないため、解除は設定画面から行ってください。アプリを再起動しても解除されます。

最前面と枠なし・背景透過は、次回起動時も引き継ぎます。
なお、排他的フルスクリーンで動作するゲームの上には表示できません。ゲーム側をボーダーレスウィンドウやウィンドウモードにしてください。

## レス表示HTMLサンプル
細かい設定によって変わりますが、レス1つで以下のような構造のHTMLとなります。
CSS編集の際に参考にしてください。

```html
<li class="list-item">
    <span class="icon-block">
      <img class="icon" src="./img/random/sanma_1.png">
    </span>
    <div class="content">
      <span class="resNumber">34</span>
      <span class="name">名無し</span>
      <span class="date">2020/07/21(火) 00:11:24</span><br>
      <span class="res">
      ﾃｽﾃｽｗｗｗｗｗｗｗｗｗｗｗｗｗｗｗ
    </span>
  </div>
</li>
```

## アイコン

2ch互換掲示板のレス表示は、アイコンがランダム表示となります。
変更したい場合は**unpack版**を利用してください。
以下のフォルダにある`.png`をランダムで表示します。
`unacast-win32-x64/resources/app/public/img/random`
